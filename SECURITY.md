# Security Policy

## Supported Versions

Only the latest release of POINTLESS is supported with security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report it privately via [GitHub Security Advisories](../../security/advisories/new)
for this repository, or by opening a private conversation with the maintainer.

Include as much detail as possible:
- Steps to reproduce
- Affected version / commit
- Potential impact

You should expect an initial response within a few days. If the issue is
confirmed, a fix will be prioritized and a new release published; you'll be
credited in the release notes unless you prefer otherwise.
